Manual Data Editor Workflow Map

A clickable field guide to the package correction loop: where a buyer edits a dashboard-like value, what only sends a refresh request, what writes warehouse evidence, and how valid manual values flow back into reporting.

Live check used for this map BigQuery MCP confirmed the raw and daily manual tables exist, are described, and were modified on 2026-06-18. The model and mart views expose the current man_* evidence fields.
Source of truth Writes data or sends a notification Manual touchpoint Low failure risk Medium failure risk High failure risk
Baseline The current source value the loader compares against. If the sheet value matches the baseline, there is no manual override to keep.
man_* evidence Backend fields that prove a value came from the Manual Data Editor, such as man_daily_spend.
Daily spread A total entered for a date range is divided into package/date rows, then checked so the rows add back to the edited total.
Mart The dashboard-ready view built from the evidence model after reporting-only filtering and rollup recalculation.
