# Final Model

Current final path for the master data model: the clustered v3 table with creative/detail support.

This is the first folder to check when the question is about the current final table shape, grain, creative behavior, or the universal runner's v3 refresh.

V3 also carries digital conversion outcome rows from the digital conversions branch. Those rows keep package/date/site/creative/activity detail, leave delivery metrics blank, and use `conv_*` fields for conversion activity, source impressions/clicks, and Sheet lineage.
